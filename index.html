tvidea

A TV channel for gaming videos, playing quietly in the background.

  1. Open console.cloud.google.com → YouTube Data API v3 and create (or pick) a project.
  2. Click Enable to turn the YouTube Data API v3 on for that project.
  3. Open Credentials in the sidebar, then Create Credentials → API key.
  4. Copy the key it gives you and paste it below.

Your key is stored only in this browser and is only ever sent to Google.
